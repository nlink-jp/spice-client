# 検証記録

実施日: 2026-09-17。Apple Silicon、macOS 27、Xcode / Swift 6.3。
対象 OS は macOS 26 以降ですが、最低対応版そのものでは別途試験していません。
成果物はローカル開発ビルドであり、公開済み・公証済みリリースではありません。

## 実施済み

- 元プロジェクトの追跡対象76ファイルを確認し、採用・再実装・除外を対応表に記録。
  元の spice-mac 作業コピーは変更していません。
- `make test`: 解析、origin / Cookie、一度限りの承認、状態遷移、入力、クリップボード権限、
  ファイル保全、UTIに依存しない選択、言語、メニュー、継承したCookie期限の回帰テスト。
  依存ファイルと文書リンクの検査、および不正ZIPを拒否するPython 3テストも含みます。
- `make simulate`: 条件付きのシミュレーション4件を含むSwiftの登録38テストが通過。
  実WebKitでローカルHTTPSの自動location遷移・form POSTを実行し、ネイティブ確認なしでは
  セッションが作られないことを確認。実URLSessionのリダイレクトでCookieを再選別しました。
  別origin、上限超過、不正UTF-8、本文切れは拒否し、gzipは受理しました。
  証明書の一時承認でも、別ホスト名と有効期限外の日付は拒否しました。
- 疑似SPICEサーバーはループバックTCPで実際のバイナリ形式を送受信。
  本物のSwiftSpice通信とSessionControllerで接続初期化を行い、Ctrl-Alt-Deleteの入力6パケットを送信。
  認証失敗、不正ハンドシェイク、応答を停止した接続途中の取消を試験しました。
  受信接続6・切断6・入力パケット6・パス制限Cookieの漏れ0を確認。
- `make test-vendor`: **SwiftSpiceの897テストが通過**。
  実エージェント管理処理を通す共有解除・再通知の追加回帰テストを含みます。
  最初の全面同時実行ではファイル処理fixtureが停止したため終了し、順次実行で完了しました。
  合格のために上流テストを削除していません。
- `make build`: 最適化ビルド、Metalの実コンパイル、アプリ組み立て、動的ライブラリの
  持ち運び可能性検査、ローカルのアドホック署名検証が成功。
- 完成アプリの画面確認: 日本語ランチャー・版数・メニュー、実ファイル選択、接続先を表示した
  確認画面、共有OFFと平文通信の説明、取消による復帰を確認。
  この操作で見つかったUTI競合を修正し、同じファイルが選択可能になったことを確認しました。
- 同梱の2つのMetalライブラリを読み込み。両方の開発用 `.build` を一時的に隠した状態でも、
  別の場所にコピーしたアプリの `--smoke-test` による起動・終了を確認。
- 設計と実装の独立レビューを実施。再試行時の共有、2台目のポータル候補、最終ZIP検証の
  3指摘を修正して再確認しました。その再確認で追加の高影響の不具合は報告されていません。

## 未検証・対象外

実QEMU / Ravada接続先がないため、利用者の明示指定に従ってシミュレーションで検証しました。
実ゲストの映像、実音声出力、実クリップボード内容、解像度交渉、長時間の入力、ゲスト接続中の
フルスクリーン、実H.264→MJPEG再接続は未検証です。
上流のコーデック・音声・Metal単体テストは、その相互運用・実機確認の代わりにはなりません。
Finderのダブルクリック・重複プロセス間のファイル引き渡し、macOS 26での挙動も全面的には確認していません。
ネイティブのファイル選択は別途実操作しました。

ネイティブ依存は変更していない固定アーティファクトです。バイナリ全体の逆解析や無欠陥の保証はしていません。
418ファイルのハッシュ、シンボリックリンク、ネイティブ28項目のハッシュ、ローカルパッチを追跡しています。
元の更新機能は継承していません。

配布検証は不正ZIPを拒否し、指定された最終ZIPの内容を検証する構造にしました。
Developer ID署名・公証・一般公開は実施していないため、リリースZIP検証済みとは扱いません。
リモートリポジトリ、umbrellaのsubmodule、組織プロフィールは変更せず、作業は `_wip/` に保持しています。
組織全体の初回確認では `cli-series` と `lab-series` の既存変更が報告されました。
最終確認では、この変更とは無関係な `util-series` の未コミット変更と、`active-lens`、
`active-lens-gui` のsubmodule参照の差異、計3件が報告されました。それらのプロジェクトは変更していません。SwiftプロジェクトのためGoの検査は対象外です。
再利用可能なWebKit検証の知見は、組織のknowledgeに日英で還元しました。

## 再実行

`make test`、`make test-vendor`、`make simulate`、`make build` の順に実行します。
シミュレーションの鍵・チケットは一時領域で生成して削除し、永続的なfixture秘密鍵や実認証情報は含めません。
